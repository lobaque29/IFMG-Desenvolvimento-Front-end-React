## Arquivos na raiz

Os arquivos individuais da raiz são exercícios introdutórios de JavaScript, HTML, eventos e React. Eles foram mantidos no local original nesta primeira reorganização para preservar compatibilidade.

## Como estudar

1. Comece por `Introduçao Html`.
2. Continue pelos exercícios de JavaScript e eventos na raiz.
3. Avance para as pastas de CSS e formulários.
4. Finalize com `exercicio react` e os componentes `.jsx`.

## Observações

- Pastas e arquivos originais foram mantidos para não alterar caminhos usados pelos exercícios.
- Arquivos temporários do Windows, como `desktop.ini`, são ignorados pelo Git.
- A organização detalhada está documentada em [`docs/ORGANIZACAO.md`](./docs/ORGANIZACAO.md).
