## Como usar

- Comece pelo módulo `01-html` para fundamentos de HTML.
- Em seguida, continue em `02-javascript` e `03-eventos`.
- Depois, use `05-css-e-formularios` para CSS e formulários.
- Finalize em `08-react` para exercícios de React.
